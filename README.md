# 🤖 AI Chatbot

A beginner-friendly AI chatbot built with Python, Streamlit, and the Google Gemini API.

## ✨ Features

- 💬 AI-powered conversations
- 🧠 Conversation memory
- 🤔 Thinking/loading indicator
- 💡 Example prompts
- 🧹 Clear chat
- 🎨 Clean and simple UI
- 🔐 Secure API key using `.env`

## 🛠️ Technologies

- Python
- Streamlit
- Google Gemini API
- Google GenAI SDK
- python-dotenv
